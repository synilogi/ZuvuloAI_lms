# LMS-007 — Assignment UI

## Goal
Create assignment authoring and submission-review UI.

## Screens
1. Assignment List
2. Assignment Editor
3. Assignment Preview
4. Submission List
5. Submission Detail

## Assignment Editor
Include:
- title
- instructions
- attachments placeholder
- due date
- maximum score
- submission type
- rubric/criteria
- status

## Submission List
Show:
- student
- submission status
- submitted time
- score
- review status
- action

## Submission Detail
Show assignment requirements, student response/file placeholders, grading area, feedback area, and submit-review action.

## States
No assignments, no submissions, loading, validation, success, error.

## Responsive
Use cards for submission review on mobile.

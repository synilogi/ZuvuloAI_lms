# LMS-013 — LMS Calendar

## Goal
Create a unified LMS schedule interface.

## Screens
1. Calendar
2. Event Detail
3. Create/Edit Event

## Events
Represent:
- live classes
- assignments due
- quizzes
- course milestones
- personal learning reminders

## Calendar
Provide month/week/list views where consistent with the project.
Use clear event labels and filters.

## Event Detail
Show event type, course, instructor, date/time, duration, description, and action.

## States
No events, loading, selected day with no events.

## Responsive
Prefer list/agenda view on small screens.

# LMS-002 — Course Management

## Goal
Create the complete course administration UI.

## Screens
1. Course List
2. Create Course
3. Edit Course
4. Course Details
5. Curriculum Overview
6. Course Preview
7. Publish Confirmation
8. Archive Confirmation

## Course List
Header:
- breadcrumb
- title
- course count
- Add Course CTA

Toolbar:
- search
- category filter
- instructor filter
- status filter
- sort
- grid/list view where appropriate

Course representation:
- thumbnail/cover
- title
- category
- instructor
- chapters/lessons count
- enrollment count
- status
- updated date
- actions

Actions:
- view
- edit
- preview
- publish/unpublish
- archive

## Create/Edit
Sections:
- course identity
- cover/thumbnail area
- description
- category
- instructor
- level
- duration
- learning outcomes
- tags
- status/visibility
- save/cancel

Use a clear multi-section form without overwhelming the user.

## Details
Provide course overview, metadata, instructor, curriculum summary, enrollment snapshot, and actions.

## Curriculum
Show chapters and lessons in an expandable hierarchy with ordering affordances.

## States
Loading, empty, no-search-results, validation, success, error, archive/publish confirmation.

## Responsive
Mobile converts dense tables into cards and keeps primary actions accessible.

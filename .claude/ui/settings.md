# LMS-016 — LMS Settings

## Goal
Create LMS-specific settings within the existing SyniastroLMS settings pattern.

## Screens
1. LMS General
2. Course Settings
3. Learning Settings
4. Certificate Settings
5. Notification Settings
6. Appearance/Branding Preview

## General
Include:
- LMS name/display label
- default course visibility
- default enrollment behavior
- default lesson settings

## Learning
Include:
- progress rules
- completion behavior
- learner preferences

## Certificate
Include:
- certificate enable/disable
- display fields
- branding preview

## Notifications
Include grouped preference controls.

## UX
Use the existing settings navigation pattern. Use clear section descriptions, toggles, selects, inputs, and save feedback.

## States
Loading, unsaved changes, validation, saved success, error.

## Responsive
Settings navigation collapses into a selector or stacked sections on mobile.

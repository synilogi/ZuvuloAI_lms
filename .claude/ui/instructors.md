# LMS-009 — Instructor UI

## Goal
Create instructor management and profile UI.

## Screens
1. Instructor List
2. Add/Edit Instructor
3. Instructor Profile
4. Instructor Courses
5. Instructor Performance

## List
Show:
- avatar
- name
- expertise
- courses
- students
- rating/performance indicator
- status
- actions

## Form
Include profile identity, bio, expertise, display image placeholder, status, and assigned courses.

## Profile
Show bio, expertise, course portfolio, student reach, performance summary, and recent activity.

## States
Loading, empty, validation, success, error.

## Responsive
Cards on mobile.

# LMS-010 — Learner Learning Experience

## Goal
Create the learner-facing course consumption experience.

## Screens
1. My Learning
2. Course Learning Overview
3. Lesson Player
4. Lesson Navigation
5. Lesson Completion
6. Course Progress
7. Learning Empty State

## My Learning
Show:
- continue learning
- enrolled courses
- progress bars
- recently accessed lessons
- upcoming learning/live sessions

## Course Learning
Header:
- course title
- progress
- chapter/lesson context

Main:
- lesson content/player area
- lesson title
- description
- resources
- previous/next
- mark complete
- notes/bookmark UI where useful

Sidebar on desktop:
- chapter/lesson curriculum
- completion indicators

## Lesson Types
Provide appropriate learner UI for video, article, PDF, quiz, assignment, and live-session placeholders.

## States
Loading, empty, unavailable lesson, completed lesson, error.

## Responsive
Desktop uses player + curriculum; mobile uses player/content first and collapsible curriculum.

# LMS-005 — Lesson Management

## Goal
Create the complete lesson authoring UI.

## Screens
1. Lesson List
2. Add Lesson
3. Edit Lesson
4. Lesson Editor
5. Lesson Preview
6. Lesson Settings

## Lesson Types
Represent:
- video
- article/text
- PDF/document
- quiz
- assignment
- live session

## Lesson List
Show:
- lesson number
- title
- type
- chapter
- duration
- status
- updated date
- actions

## Lesson Editor
Include:
- lesson title
- lesson type selector
- content/editor area
- media/document placeholder area
- description
- learning objectives
- duration
- free preview toggle
- visibility/status
- save/preview actions

## Curriculum Context
Show course and chapter context prominently.

## UX
Use tabs/sections for content and settings when useful.
Make content authoring the primary focus.

## States
Empty, loading, unsaved changes, validation, preview, success, error.

## Responsive
Desktop can use a two-column editor; mobile becomes single-column with sticky primary action.

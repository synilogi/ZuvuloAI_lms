# LMS-011 — Certificate UI

## Goal
Create certificate achievement and management UI.

## Screens
1. Certificate List
2. Certificate Detail
3. Certificate Preview
4. Certificate Template/Style Preview

## List
Show:
- certificate name
- course
- student
- issue date
- status
- verification indicator
- actions

## Detail
Show a premium certificate preview with:
- SyniastroLMS branding
- learner name
- course
- completion date
- certificate ID placeholder
- signature placeholders

Include view/download/share UI buttons visually; no real file generation required.

## States
Empty, loading, unavailable, success, error.

## Responsive
Certificate preview remains legible on mobile with horizontal-safe layout.

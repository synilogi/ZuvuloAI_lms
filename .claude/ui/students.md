# LMS-008 — Student UI

## Goal
Create learner management UI.

## Screens
1. Student List
2. Student Profile
3. Student Enrollments
4. Student Progress
5. Student Activity

## List
Show:
- avatar
- student name
- email/identifier
- enrolled courses
- progress
- last activity
- status
- actions

Include search, course filter, status filter, and sorting.

## Profile
Use a profile header with:
- identity
- status
- enrollment summary
- progress summary

Sections:
- courses
- progress
- activity
- achievements/certificates preview

## States
Loading, empty, search empty, error.

## Responsive
Profile uses stacked sections on mobile; list becomes cards.

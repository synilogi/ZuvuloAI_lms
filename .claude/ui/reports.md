# LMS-015 — LMS Reports

## Goal
Create premium reporting UI using mock data.

## Screens
1. Reports Overview
2. Course Performance
3. Student Progress
4. Instructor Performance
5. Completion/Enrollment Report

## Controls
- date range
- course
- category
- instructor
- learner segment where relevant

## Metrics
- enrollments
- completion rate
- active learners
- average progress
- quiz performance
- assignment performance
- course engagement

## Visuals
Use a restrained mix of charts, tables, KPIs, and trend indicators. Do not create a dashboard made entirely of cards.

## States
Loading, no data, filtered no results, error.

## Responsive
Charts should remain readable; tables can horizontally scroll or transform into summaries on mobile.

# LMS-001 — LMS Dashboard

## Goal
Create the primary LMS command center inside the existing SyniastroLMS App Shell.

## Screens
1. LMS Dashboard

## Header
- Breadcrumb
- "LMS Dashboard" title
- concise contextual subtitle
- primary action for adding a course
- optional secondary quick action

## Main Content
Create a balanced dashboard with:
- active courses KPI
- total students KPI
- instructors KPI
- completion/enrollment KPI
- course performance overview
- student learning activity
- upcoming live classes
- recent LMS activity
- top/recommended courses
- quick actions

## UX
Use clear visual hierarchy rather than a wall of cards.
Charts may use mock data where appropriate.
Use tabs or segmented controls only when they improve comprehension.

## States
Loading skeleton, no-data state, populated state, and error state.

## Responsive
Desktop dashboard grid; tablet reorganizes sections; mobile stacks content with priority actions first.

## Acceptance
Dashboard feels like an extension of SyniastroLMS, not a generic SaaS analytics template.

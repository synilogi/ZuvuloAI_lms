# LMS-012 — Live Class UI

## Goal
Create live learning session management and learner schedule UI.

## Screens
1. Live Class List
2. Create/Edit Live Class
3. Live Class Detail
4. Upcoming Session
5. Session History

## List
Show:
- class title
- instructor
- course
- date/time
- duration
- status
- enrolled count
- action

## Form
Include:
- title
- description
- course
- instructor
- date
- start/end time
- meeting placeholder
- capacity
- visibility/status

## Detail
Show session information, instructor, attendees preview, agenda, reminders, and join/start CTA states.

## States
Upcoming, live, completed, cancelled, empty, loading, error.

## Responsive
Timeline/list becomes cards on mobile.

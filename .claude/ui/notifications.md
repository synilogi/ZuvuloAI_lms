# LMS-014 — LMS Notifications

## Goal
Create learner/admin notification UI.

## Screens
1. Notification Center
2. Notification Detail
3. Notification Preferences

## Notification Types
- course update
- assignment
- quiz
- live class
- certificate
- enrollment
- system

## Center
Show unread/read states, timestamps, category/icon, and clear-all/mark-read interactions.

## Preferences
Provide grouped notification toggles with clear descriptions.

## States
No notifications, loading, unread, read, error.

## Responsive
Mobile-first notification list.

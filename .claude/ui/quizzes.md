# LMS-006 — Quiz UI

## Goal
Create a professional quiz builder UI.

## Screens
1. Quiz List
2. Quiz Builder
3. Question Editor
4. Quiz Preview
5. Quiz Settings
6. Results Preview

## Question Types
Support UI for:
- single choice
- multiple choice
- true/false
- short answer

## Builder
Show:
- quiz title
- instructions
- question count
- question list
- question ordering
- add question
- duplicate
- delete
- mark correct answer
- points
- explanation
- required toggle

## Settings
- passing score
- attempts
- time limit
- randomization
- show results

## Preview
Provide learner-facing preview with progress and answer states.

## States
Empty quiz, unsaved changes, validation, preview, success, error.

## Responsive
Question list becomes a compact mobile selector and editor remains readable.

# LMS-003 — Course Categories

## Goal
Create a polished category management experience.

## Screens
1. Category List
2. Create Category
3. Edit Category
4. Category Details/Delete Confirmation

## Category List
Show:
- category name
- description
- course count
- status
- updated date
- actions

Include:
- search
- status filter
- add category
- sorting where useful

## Form
Fields:
- name
- short description
- icon/image representation
- status
- display order

## UX
Use inline actions or a contextual menu for edit/view.
Deletion should use a confirmation dialog with impact information.

## States
Empty, search empty, loading, validation, success, error.

## Responsive
List becomes compact cards on mobile.
